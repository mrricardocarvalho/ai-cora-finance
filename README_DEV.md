# Developer quickstart

1. Install dependencies

```bash
npm install
```

2. Start development server

```bash
npm run dev
```

3. Optional: initialize shadcn UI

```bash
npx shadcn-ui@latest init
```

4. Build and run production server

```bash
npm run build
npm run start
```

5. Smoke test (requires the server running on http://localhost:3000)

```bash
npm run smoke
```
