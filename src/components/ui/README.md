shadcn/ui placeholder components

This folder contains minimal placeholder UI components to satisfy Story 1.1 and to be replaced or extended by an actual `shadcn/ui` initialization.

To fully initialize shadcn/ui, run:

```bash
npx shadcn-ui@latest init
```

Recommended options: Default style, `slate` base.

Dev notes:
- After running `npx shadcn-ui@latest init`, commit generated files under `src/components/ui` and `src/styles` to complete the UI setup.
